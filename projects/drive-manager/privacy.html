Privacy Policy

Updated: December 30, 2025

This Privacy Policy describes how the Drive Manager add-on for Google Docs and Sheets handles your information.

1. Data Collection

The Drive Manager add-on does not collect, store, or transmit any personal data. All operations occur entirely within your Google Workspace account using Google Apps Script.

2. Data Access

Drive Manager requires the following Google OAuth scopes:

  • https://www.googleapis.com/auth/drive – to display your Google Drive files and folders, and allow you to rename, move, delete, or upload files as part of the file manager functionality.
  • https://www.googleapis.com/auth/script.container.ui – to render the sidebar interface inside Google Docs and Sheets.

These scopes are used exclusively to enable file management features inside the Google Docs and Sheets interface. The add-on does not access file contents.

3. Data Storage

No user data is stored, logged, or transmitted to any external server. All data access is performed in real-time through Google Drive API and handled entirely within the Google Apps Script environment.

4. Data Sharing

Drive Manager does not share any user information or file metadata with third parties. All actions are initiated manually by the user and remain within the user's Google account.

5. Use of Google User Data

The add-on’s use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Changes to This Policy

This Privacy Policy may be updated from time to time. Any material changes will be reflected on this page with an updated effective date.

7. Contact

If you have any questions regarding this Privacy Policy or the Drive Manager add-on, please contact us at znhv@yandex.com.
